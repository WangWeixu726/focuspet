- The public `WangWeixu726/focuspet` repository was created and synchronized.

## Git and GitHub Concepts Learned

- A repository contains project files and their version history.
- A `commit` is a local snapshot; `push` publishes local commits to GitHub.
- `origin` is the conventional local alias for the GitHub remote address.
- Browser login and terminal Git authentication are separate; the SSH key handles terminal authentication.
