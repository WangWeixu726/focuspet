# FocusPet

一只住在桌面上、陪伴专注学习的养成宠物。

> 当前阶段：方案已经确定，功能代码尚未开始。目标是在 2026 年 10 月 31 日完成 `v1.0`，并通过独立实现与讲解验收。

## 核心体验

1. 开启番茄钟，宠物进入陪伴状态。
2. 完成专注后获得金币和经验。
3. 使用奖励购买衣服、食物或小道具。
4. 拖动宠物时它会被拎起并左右摆动；松手后会落到地面或平台。
5. 可以指定目的地让宠物自己前往，也可以切换为允许停在任意位置的自由模式。

## `v1.0` 验收范围

- [ ] 透明、无边框、置顶的桌宠窗口
- [ ] 待机动画与点击互动
- [ ] 拖动、拎起、左右摆动和松手下落
- [ ] 地面与至少两个自定义落脚平台
- [ ] 自由模式与平台模式
- [ ] 指定目的地后自动移动
- [ ] 番茄钟的开始、暂停、继续和完成
- [ ] 完成专注后获得金币与经验
- [ ] 商店、背包和至少三件可装备物品
- [ ] 本地存档，重启后保留状态
- [ ] 基础自动测试、运行说明和演示素材

## 暂定技术路线

- Python 3.14
- PySide6：桌面窗口、鼠标事件、计时器和动画
- JSON：第一版存档
- pytest：自动测试

选择 PySide6 是因为这个项目需要透明无边框窗口、置顶显示、鼠标拖动和计时事件。第一阶段先使用简单占位图，避免素材制作盖过 Python 学习本身。
