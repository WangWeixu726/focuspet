## Concepts I Can Explain Now

- A virtual environment gives one project its own Python executable and package directory, preventing dependency conflicts with the system Python and other projects.
- `git add` selects changes for the next snapshot, `git commit` records that snapshot locally, and `git push` synchronizes local commits to GitHub.
- A GUI application stays responsive because `app.exec()` runs an event loop that waits for window and input events.
- A class groups the data and behavior that belong to one kind of object; `PetWindow` is now the blueprint for every FocusPet window.
- Window flags change operating-system-level window behavior, while a widget attribute such as `WA_TranslucentBackground` changes a specific Qt property.
- The `|` operator combines multiple independent window flags without replacing one with another.
- Qt calls mouse event methods automatically when the user presses, moves, or releases a mouse button over the window.
- Subtracting the grab offset from the pointer's global position keeps the same point under the pointer throughout a drag.
- `None` represents the idle state: there is no active drag to update.
