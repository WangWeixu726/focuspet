## Problems and Solutions

- A newly opened terminal could not find `python` because virtual-environment activation applies only to the current shell session. I entered the project directory and ran `source .venv/bin/activate` again.
- The first run of `main.py` raised a `SyntaxError` because the imported names were placed on a separate line and `QtWidgets` used incorrect capitalization. I combined the import into one line and corrected the module name.

## Concepts I Can Explain Now

- A virtual environment gives one project its own Python executable and package directory, preventing dependency conflicts with the system Python and other projects.
- `git add` selects changes for the next snapshot, `git commit` records that snapshot locally, and `git push` synchronizes local commits to GitHub.
- A GUI application stays responsive because `app.exec()` runs an event loop that waits for window and input events.
